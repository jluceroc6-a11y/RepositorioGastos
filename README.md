
Proyecto de Registro de Gastos

Descripción del proyecto

Este proyecto consiste en un programa de consola desarrollado en C# que permite registrar y consultar gastos utilizando una base de datos llamada GastosBD.

El programa busca facilitar el control de los gastos, permitiendo guardar información como la descripción, el monto y la categoría de cada gasto.

¿En qué consiste la tarea?

La tarea consiste en crear un programa que se conecte a una base de datos y permita realizar dos operaciones principales: registrar nuevos gastos y mostrar los gastos que ya se encuentran guardados.

Para realizar el proyecto se utilizaron tres archivos principales:

* Program.cs: contiene el menú principal y permite al usuario elegir qué acción realizar.
* Gastos.cs: contiene los datos de cada gasto, como el ID, la descripción, el monto y la categoría.
* RepositorioGastos.cs: se encarga de conectarse a la base de datos, guardar los gastos y consultar los registros existentes.

También se utilizaron consultas parametrizadas para registrar la información en la base de datos.

Funcionamiento

Al ejecutar el programa, se muestra un menú con las siguientes opciones:

1. Registrar un gasto.
2. Listar los gastos registrados.
3. Salir del programa.

El usuario puede ingresar los datos de un gasto y guardarlos en la base de datos. También puede consultar los gastos registrados y verificar la información almacenada.

El programa incluye una validación básica para evitar que se guarden datos incorrectos.

Objetivo del proyecto

El objetivo es poner en práctica los conocimientos aprendidos en clase sobre programación en C#, conexión a bases de datos y manejo de información mediante consultas SQL.
